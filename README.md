복지 관련 필요한 앱을 개발 공유하는 곳
# 🛡️ 배리어프리 1인 가구 안전망 플랫폼 (Barrier-Free Solo CareTech)

## 📌 프로젝트 소개
본 프로젝트는 보호자가 없는 1인 가구, 특히 **뇌성마비 및 발달장애 당사자와 기초생활수급자**가 지역사회에서 안전하고 주체적으로 살아갈 수 있도록 돕기 위해 개발된 **단일 파일 기반(Single-file) 웹 애플리케이션** 모음입니다. 

20년 경력의 복지 현장 전문가의 실무 경험을 바탕으로, 복잡한 설치 없이 브라우저에서 즉시 실행되며, 오프라인 및 인쇄 환경까지 고려하여 설계되었습니다.

## 📱 포함된 애플리케이션
1. **`general-solo.html`** : 1인 가구 60대 전 필수 안전망 플래너
   - 긴급 의료 요약지 생성 및 119 안심콜/사전연명 등 5대 안전망 체크리스트
2. **`basic-welfare.html`** : 기초생활수급 뇌성마비 1인 가구 맞춤형 플래너
   - 의료급여 연계, 뇌성마비 신체특성 고지 보드, 공공성년후견 및 주치인지원 안내
3. **`easy-read-aac.html`** : 발달/뇌성마비 쉬운 말(Easy-read) & 대형 AAC 보드
   - 슈퍼 자이언트 버튼, 직관적 이모지, Web Speech API 기반 원터치 음성 발화

## ✨ 핵심 기능 (Features)
* **Barrier-Free UI**: 조음장애 및 불수의 운동(손떨림)을 고려한 대형 타겟 버튼 적용.
* **고대비 모드 (High Contrast)**: 저시력자를 위한 흑황(Yellow on Black) 테마 즉시 전환.
* **음성 낭독 (TTS AAC)**: 진료실이나 응급상황 시 스마트폰 스피커로 본인의 상태를 알릴 수 있는 원터치 발화 기능.
* **A4 출력 최적화**: 웹 UI를 숨기고 관공서/응급실 제출용 흑백 규격 문서로 즉시 출력.
* **로컬 보안 저장**: 민감한 의료/개인정보는 서버로 전송되지 않고 브라우저(`localStorage`)에만 안전하게 보관됨.

## 🛠 기술 스택
* HTML5, CSS3, Vanilla JavaScript
* Web Speech API (TTS 기능)
* FontAwesome (아이콘)
